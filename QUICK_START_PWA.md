## ❓ Troubleshooting

### **"I don't see the install button"**
- Wait 30 seconds - service worker needs to register
- Refresh the page
- Clear browser cache: Settings → Apps → [Browser] → Storage → Clear

### **"Service Worker not working"**
- Refresh (Ctrl+R or Cmd+R)
- Check internet connection
- Try a different browser
- Clear cache and reload

### **"App crashes after install"**
- Uninstall and reinstall
- Clear app data
- Check internet connection for API calls
- Report error details

### **"Offline features not working"**
- Open app online first (to cache content)
- Service worker needs 30-60 seconds to cache
- Check browser storage quota
- Some features require internet (API calls)
